# Сессия 26.10.2026 — HTML diff оферт и сверка с рынком

## Задача (владелец, дословно, сокращено только по повторам)
«Сформируй мне файл HTML что-то изменил по принципу diff чтобы я понимал какие были блоки Какие стали Аргументируй Почему и что это подтверждает офертами других сайтов … есть специальная методология определение истины … Используя большое количество источников, делая явное усреднение, подтверди, что такое существует и можем ли мы эту матрицу разложить сюда. … через Tavili Search … наши настройки для B2B/B2C-сегмента соответствуют.
У нас основные лица: это юридические, но могут быть и физические лица, но крайне редко по договору. В основном у нас юридические, у которых есть ИНН: это ИПшники, ОООшники, самозанятые. Договор есть, и мы расчеты на текущий момент осуществляем через счета.»

## План
1. Diff было/стало по блокам 374, 382, 384, 390, 392, 394, 396 из git (коммиты 26.10).
2. Tavily: 5–6 оферт интеграторов Битрикс24 / IT-услуг — адресаты, акцепт, ПДн, лимит, изменение условий, подсудность. Матрица и «середина».
3. Методология: триангуляция / бенчмаркинг / обычай — существует ли, где граница применимости (закон > рынок).
4. Новое от владельца: самозанятые — физлица (НПД). Проверить, не исключает ли их текущая B2B-оговорка.
5. HTML (светлая тема) → `docs/research/2026-10-26-offers-diff.html`, PR в dev, файл владельцу.

## Журнал
- Diff: `docs/research/offers-diff/mkdiff.py` (git show b8e1813^ против origin/dev, difflib по пунктам) → `diff.json`: 31 изменение (374:1, 382:1, 384:6, 390:3, 392:6, 394:10, 396:4).
- Рынок: 8 оферт (Tavily search + extract), сырые данные `docs/research/offers-diff/market-sources.md`. Наблюдение: старый текст ARWOX о ПДн = шаблон delaem-crm.ru (большинство рынка повторяет ошибку) — консенсус рынка не равен закону.
- Методология (проверено источниками): ГК ст. 5 — обычай = «сложившееся и широко применяемое … не предусмотренное законодательством правило поведения»; п. 2: «Обычаи, противоречащие обязательным … положениям законодательства или договору, не применяются» (consultant.ru). Фактчекинг: «минимум два-три подтверждения»; «если все они … находятся в одном лагере … количество не работает» (mediatoolbox.ru). Решение: иерархия закон → договор → рынок; источники одного шаблона считаются за один.
- Самозанятые: по НПД — физлица (422-ФЗ, klerk.ru/documentoved.ru). Текущая оговорка «только юрлица и ИП» + «оплата с личного счёта гражданина акцептом не является» исключает самозанятых-клиентов, о которых сказал владелец → N-11. Применим ли ЗоЗПП к самозанятому-покупателю для его деятельности — прямых источников не найдено, UNVERIFIED (найдены только случаи самозанятого-исполнителя).
