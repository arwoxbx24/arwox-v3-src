## U2 — token sanity check (qj6w1, owner 16.10: close by code)

File: `index.py` `_captcha_ok` (:111-131) + a case in `test_lead.py`. Before calling the validator: token longer than 4096 chars → return `'fail'` (captcha error page, no lead, no validator call). Why: an oversized garbage token must not reach the validator and come back as 5xx/timeout → `'unavailable'` → lead with prefix. No charset rule: the token format is not documented, a charset guess could reject real visitors. Replay is handled by Yandex: «`token` — одноразовый токен» (https://yandex.cloud/ru/docs/smartcaptcha/quickstart).
Acceptance: test case — 5000-char token → `'fail'`, 0 urlopen calls; existing tests PASS (incl. the `captcha-unavailable` stub token path).
